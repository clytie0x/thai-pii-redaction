Chrome Extension 3.0.0

Chrome Web Store ยังไม่มีหน้ารายการที่เผยแพร่ ขณะนี้ใช้ได้เฉพาะ Manual / Developer installation จาก ZIP ทางการ โดยต้องติดตั้งและเปิด AI Guard Desktop 3.0.0 ก่อนเพื่อให้ Native Messaging ทำงาน

  1. ดาวน์โหลดไฟล์ ZIP แล้วแตกไฟล์ ZIP ไปยังโฟลเดอร์ที่เก็บถาวร
  2. เปิด chrome://extensions แล้วเปิด Developer mode
  3. เลือก Load unpacked และเลือกโฟลเดอร์ที่แตกไว้
  4. เปิด AI Guard Desktop 3.0.0 ก่อนทดสอบการเชื่อมต่อจากส่วนขยาย
ขอบเขตข้อมูลดิบ: การใช้ In-page Mask เริ่มหลังข้อความดิบเข้า DOM ของเว็บไซต์ AI แล้ว โค้ดของเว็บไซต์อาจเห็นหรือส่งข้อความนั้นได้ก่อนการปกปิด หากต้องการแยกข้อมูลดิบให้มากขึ้น ให้กรอกใน AI Guard Side Panel แล้วนำเฉพาะข้อความที่ปกปิดและตรวจทานแล้วไปวาง — Side Panel เป็นขอบเขตที่แข็งแรงกว่า อ่าน ขอบเขตความปลอดภัยของ Desktop และ Extension
