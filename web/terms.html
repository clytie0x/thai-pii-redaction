ตรวจทานได้

Hosted 3.0.0 ให้ Standard access และ Priority Invite ทั้งสองแบบมีความจุจำกัดและไม่แทนความรับผิดชอบของผู้ใช้ในการตรวจผล

ฉบับข้อมูลผลิตภัณฑ์

มีผล 17 สิงหาคม 2569 ข้อมูลโครงการยังไม่ระบุนิติบุคคลหรือเขตอำนาจศาล จึงไม่ใช่ข้อกำหนดองค์กรฉบับสมบูรณ์

ข้อกำหนดสิทธิ์เข้าถึงความรับผิดชอบสิ่งต้องห้ามสิ่งที่ไม่รับรองขอบเขตผลิตภัณฑ์

การใช้ Hosted หมายถึงคุณยอมรับว่าข้อความต้นฉบับผ่าน AI for Thai edge และเซิร์ฟเวอร์ Team 08 และผลการตรวจจับหรือผลจากโมเดลอาจผิดพลาดได้ หากขอบเขตนี้ไม่เหมาะกับงาน ให้ใช้ Desktop

สิทธิ์เข้าถึง

Hosted 3.0.0 ให้เริ่ม Standard access ต่อ signed browser session ได้ทันที หรือใช้ Priority Invite ที่ออกให้ ห้ามเผยแพร่ ขายต่อ หรือส่งต่อ invite และบริการอาจจำกัดหรือเพิกถอน session เพื่อดูแลความปลอดภัย ต้นทุน และความพร้อมใช้งาน

ความรับผิดชอบของผู้ใช้

  • มีสิทธิ์ใช้ข้อมูลที่นำเข้าสู่ระบบและปฏิบัติตามนโยบายขององค์กรตนเอง
  • หลีกเลี่ยงข้อมูลจริงที่มีความเสี่ยงสูง และเลือกข้อมูลสังเคราะห์หรือข้อมูลที่ลดทอนแล้วเมื่อทำได้
  • ตรวจข้อความที่ปกป้อง ผลการกู้คืน และรายงานก่อนนำไปใช้
  • ให้มนุษย์ตรวจทานก่อนการแพทย์ กฎหมาย การจ้างงาน การศึกษา หรือการตัดสินใจที่มีผลกระทบสูง

สิ่งที่ไม่อนุญาต

  • automation, scraping, load testing, การหลบ rate limit หรือการโจมตีบริการ
  • พยายามค้นหา credential, mapping, session หรือข้อมูลของผู้อื่น
  • ใช้กับเนื้อหาผิดกฎหมาย หรืออ้างว่า AI Guard รับรอง compliance หรือ anonymization
  • ส่ง access code, cookie, credential หรือข้อมูลจริงผ่านช่องทาง support สาธารณะ

สิ่งที่บริการไม่รับรอง

AI Guard ไม่รับประกันการตรวจพบ 100%, ผลโมเดล AI, uptime, SLA, ความเหมาะสมทางกฎหมาย หรือการปฏิบัติตาม PDPA โดยอัตโนมัติ Section 26 เป็น heuristic review signal และ PDPA Report ไม่ใช่ใบรับรอง

ขอบเขตผลิตภัณฑ์และการเปลี่ยนแปลง

Desktop 3.0.0, Hosted 3.0.0 และ Browser Extension 3.0.0 แบบ Manual เป็นช่องทางแยกกัน Store ยังไม่เผยแพร่ Hosted รับเฉพาะ text-layer PDF → Protected Markdown ไม่ใช่ redacted PDF หรือ OCR ดูรายละเอียดข้อมูลที่ ความเป็นส่วนตัว และไฟล์เผยแพร่ที่ ดาวน์โหลด

ข้อเท็จจริงเกี่ยวกับผู้รับผิดชอบทางกฎหมาย เขตอำนาจศาล และ private public contact ยังรอการอนุมัติจากเจ้าของ การอัปเดตส่วนเหล่านี้ต้องระบุวันที่และไม่เขียนย้อนหลัง
