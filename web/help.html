AI Guard
เว็บแอปความเป็นส่วนตัวดาวน์โหลดข้อกำหนด

ช่วยเหลือและคำถามที่พบบ่อย

คำตอบสำหรับ AI Guard Hosted private beta โดยไม่ต้องเปิดเผยรหัสเชิญ ข้อความ หรือ cookie แก่ผู้ช่วยเหลือ

เริ่มใช้อย่างไร

  1. รับรหัสเชิญจากผู้ดูแลโครงการผ่านช่องทางที่เชิญคุณเข้าร่วม
  2. เข้าสู่ระบบ แล้วเลือกตัวอย่างสังเคราะห์หรือวางข้อความที่ยอมรับขอบเขตความเสี่ยงได้
  3. ใช้ Privacy Scan ก่อน จากนั้นเลือก Token หรือ Surrogate สำหรับ Safe AI
  4. ตรวจ “ข้อความที่ส่งให้ AI” และผลการกู้คืนก่อนนำคำตอบไปใช้

ทำไมเข้าใช้ไม่ได้?

ตรวจว่ารหัสเชิญยังถูกต้องและไม่ได้เว้นวรรค การลองผิดซ้ำจะถูกจำกัด หาก session หมดอายุให้เข้าสู่ระบบใหม่โดยไม่ส่งรหัสผ่าน URL หรือข้อความแชต

ทำไม Safe AI ช้า?

คำขอ provider อาจใช้เวลาหลายนาที ระบบจำกัดคำขอซ้อนและอาจให้รอก่อนลองใหม่ อย่ากดซ้ำระหว่างคำขอยังไม่ยืนยันว่าจบ

ระบบเก็บข้อความหรือไม่?

ไม่มีฐานข้อมูลผู้ใช้และ application logs ไม่เก็บเนื้อหา ดูขอบเขต server/provider และ metadata ของแพลตฟอร์มได้ใน นโยบายความเป็นส่วนตัว

รองรับ PDF/OCR หรือไม่?

ไม่รองรับ public PDF redaction/OCR ใน deployment นี้ PDPA Report เป็นไฟล์สรุปคนละความสามารถและไม่ฝังข้อความต้นฉบับ

ติดต่อผู้ดูแล

ผู้ใช้ private beta ให้ตอบกลับผ่านช่องทางเดิมที่ได้รับรหัสเชิญ สำหรับปัญหา source code ที่ไม่ต้องเปิดเผยข้อมูลส่วนตัว สามารถใช้โครงการต้นทาง AI Guard บน GitHub โปรดส่งเฉพาะขั้นตอนทำซ้ำด้วยข้อมูลสังเคราะห์ สถานะ HTTP และ VERSION—ห้ามส่ง access code, cookie, credential หรือข้อความจริง

ข้อมูลสำหรับการแจ้งปัญหา

  • เวลาและ timezone โดยประมาณ
  • Workflow: Privacy Scan, Safe AI หรือ PDPA Report
  • สถานะที่หน้าเว็บแสดงและ HTTP status หากทราบ
  • VERSION 2.5.0
  • ตัวอย่างสังเคราะห์ที่สร้างใหม่ ไม่คัดลอกจาก production
