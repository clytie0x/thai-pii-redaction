โดยไม่ส่งข้อมูลจริง

เริ่มจากงานที่ต้องทำ อ่านสถานะบนหน้า แล้วส่งเฉพาะขั้นตอนทำซ้ำด้วยข้อมูลสังเคราะห์ อย่าส่ง access code, cookie, credential หรือข้อความจริง

ไม่มีรหัสเชิญ?

Hosted ไม่มี public signup ใช้ Desktop 3.0.0 ได้ทันที หรือขอรหัสผ่านช่องทางผู้เชิญเดิม

ตามงานของคุณเริ่มใช้สถานะและข้อผิดพลาดคำถามเรื่องข้อมูลแจ้งปัญหาAccessibility

Hosted Web เป็น Private Beta ที่ใช้รหัสเชิญ ส่วน Desktop เป็นช่องทาง local-first ที่ไม่มี provider ภายนอก หากไม่แน่ใจว่าข้อมูลออกจากเครื่องได้หรือไม่ ให้หยุดและเลือก Desktop

เริ่มจากช่องทางที่ถูกต้อง

  1. ข้อมูลต้องอยู่ในเครื่อง: ดาวน์โหลด Desktop 3.0.0
  2. มีรหัสเชิญ Hosted: เปิด Hosted Web อ่าน boundary notice ที่อยู่ติดกับช่องกรอก แล้วเข้าสู่ระบบ
  3. เริ่มด้วยตัวอย่างสังเคราะห์ เลือก Privacy Scan ก่อน แล้วตรวจสิ่งที่ระบบพบ
  4. ก่อนใช้ Safe AI ให้ตรวจ “ข้อความที่ส่งให้ AI” และผลกู้คืนทุกครั้ง
  5. PDPA Report เป็นสรุปเพื่อทบทวน ไม่ใช่คำรับรองทางกฎหมาย

สถานะและข้อผิดพลาด

เข้าใช้ไม่ได้

ตรวจรหัสเชิญและช่องว่าง การลองผิดซ้ำถูก rate limit หาก session หมดอายุให้เข้าสู่ระบบใหม่

ข้อความยาวหรือรูปแบบผิด

Hosted จำกัด 20,000 ตัวอักษร สถานะ 400/413/422 หมายถึงคำขอไม่ผ่านเงื่อนไขหรือการตรวจ fail closed อย่าลดการตรวจเพื่อฝืนส่งต่อ

บริการไม่พร้อม

สถานะ 429 ให้รอก่อนลองใหม่ ส่วน 500/502/503/504 หมายถึงบริการหรือ dependency ยังไม่พร้อม เก็บข้อความต้นฉบับไว้กับคุณและลองใหม่ภายหลัง

Safe AI ใช้เวลานาน

คำขอ provider อาจใช้หลายนาที ระบบไม่อ้างว่ายกเลิกงานฝั่ง server ได้หลังส่งแล้ว อย่ากดซ้ำจนรู้สถานะเดิม

PDF/OCR: public deployment ไม่รองรับ PDF redaction หรือ OCR และคืน 404 โดยตั้งใจ

คำถามเรื่องข้อมูล

ระบบเก็บข้อความหรือไม่?

ไม่มีฐานข้อมูลผู้ใช้และ application logs ไม่เก็บเนื้อหา แต่ Hosted ต้องรับข้อความบน edge/server เพื่อประมวลผล อ่าน lifecycle และขอบเขต provider ทั้งหมดใน หน้าความเป็นส่วนตัว

ปิดหน้าหรือ logout แล้วเกิดอะไร?

หน้าเว็บล้าง state ที่ละเอียดอ่อนและคุกกี้ session เมื่อ logout คำขอ provider ที่ส่งไปแล้วอาจยังทำงานฝั่ง server ได้ จึงไม่ควรตีความการปิดหน้าเป็นการยกเลิกปลายทาง

แจ้งปัญหาอย่างปลอดภัย

  • เวลาและ timezone โดยประมาณ
  • ช่องทางและเวอร์ชัน: Desktop 3.0.0, Hosted 2.5.0 หรือ Extension 3.0.0 Manual
  • Workflow และ HTTP status หากทราบ
  • ขั้นตอนทำซ้ำและตัวอย่างสังเคราะห์ที่สร้างใหม่

Private beta หรือเหตุการณ์ที่เป็นความลับ: ใช้ช่องทางเดิมที่ได้รับรหัสเชิญ ปัจจุบันยังไม่มี private public inbox ที่เจ้าของอนุมัติ ห้ามโพสต์รายละเอียดลับบน GitHub

ปัญหา source code ที่ไม่มีข้อมูลลับ: เปิด GitHub Issue

Accessibility feedback

บอก browser, ระบบปฏิบัติการ, เทคโนโลยีช่วยเหลือ, หน้าที่พบ และสิ่งที่คาดว่าจะเกิด โดยไม่แนบข้อมูลจริง ผู้ใช้ที่มีช่องทางเชิญใช้ช่องทางนั้นได้ ส่วนรายงานสาธารณะที่ไม่มีข้อมูลลับใช้ GitHub Issues
