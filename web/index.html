AI Guard

หยุดข้อมูลส่วนบุคคลรั่วไหลก่อนถึงมือ AI

เวลาเราวางข้อความลงแชท AI เพื่อขอให้ช่วยร่าง สรุป หรือแปล ข้อความนั้นมักมีเลขบัตรประชาชน ชื่อ เบอร์โทร หรือที่อยู่ติดไปด้วยโดยไม่ทันสังเกต และข้อความที่ส่งออกไปแล้วเรียกคืนไม่ได้ AI Guard คั่นอยู่ตรงกลาง ตรวจจับและปกปิดข้อมูลส่วนบุคคลก่อนที่ข้อความจะออกจากเครื่อง แล้วกู้คืนกลับมาให้เฉพาะฝั่งของคุณเมื่อคำตอบส่งกลับมา

ข้อมูลจริงไม่เคยเดินทางจากขั้นตอน "AI Guard ปกปิด" ไปถึงขั้นตอน "โมเดลภาษา" โมเดลปลายทางเห็นแต่โทเคนหรือข้อมูลสมมุติเท่านั้น ลองด้วยตัวเองได้ในส่วนถัดไป

หลังกดส่งในส่วน "ลองของจริง" ด้านบน ส่วนนี้จะแสดงสิ่งที่ออกจากเครื่องจริง ๆ แบบตัวต่อตัวอักษร ไม่ใช่คำสัญญาลอย ๆ

ข้อความที่ออกจากเครื่องจริง ๆ (ส่งเข้าโมเดลปลายทาง)

ยังไม่มีข้อมูล กดปุ่ม "ส่งเข้า AI อย่างปลอดภัย" ในส่วนลองของจริงก่อน

คำเตือนจากระบบ

ยังไม่มีข้อมูล
เส้นทางนี้เป็น stateless เซิร์ฟเวอร์ไม่เก็บข้อความหรือการจับคู่ระหว่างของจริงกับข้อมูลปกปิดไว้เลย ทุกอย่างจบภายในคำขอเดียวแล้วหายไป อย่างไรก็ตาม ข้อความที่ถูกปกปิดแล้ว (โดยเฉพาะโหมดข้อมูลสมมุติที่อ่านเป็นธรรมชาติ) ยังถือเป็นข้อมูลส่วนบุคคลตามกฎหมาย PDPA อยู่ดี เพราะเป็นการทำให้เป็นนามแฝง (pseudonymization) ไม่ใช่การทำให้ไม่สามารถระบุตัวตนได้อย่างถาวร (anonymization) เราไม่กล่าวอ้างเกินกว่าสิ่งที่ระบบทำได้จริง

เครื่องมือเอกสาร

เอกสาร

ใช้งานตรงจากเบราว์เซอร์ ไม่ต้องติดตั้งอะไรเพิ่ม

ทาดำ PDF

อัปโหลดไฟล์ PDF ระบบตรวจจับข้อมูลส่วนบุคคลแล้ววาดกล่องทึบทับตำแหน่งจริงในเอกสาร รองรับทั้งไฟล์ที่มีชั้นข้อความและเอกสารสแกน (มี OCR ในตัว)

รายงาน PDPA

ออกรายงานความเสี่ยงตาม PDPA เป็นไฟล์ PDF ภาษาไทย จากข้อความในช่อง "ลองของจริง" ด้านบน รายงานมีเฉพาะคะแนน เกรด และจำนวนที่พบตามหมวด ไม่มีข้อความจริงหรือค่าข้อมูลอยู่ในไฟล์

สำหรับนักพัฒนา

ใช้เป็น API และความโปร่งใส

เชื่อมต่อ AI Guard เข้ากับระบบของคุณเองผ่าน REST API ชุดเดียวกับที่หน้านี้ใช้งาน

Endpointคำอธิบายขีดจำกัด
POST /api/v1/detectตรวจจับข้อมูลส่วนบุคคลอย่างเดียว ไม่มี session ไม่มี vaultข้อความ ≤ 20,000 ตัวอักษร
POST /api/v1/guardตรวจสัญญาณ prompt injection ภาษาไทย/อังกฤษ แจ้งเตือนอย่างเดียว ไม่บล็อกข้อความ ≤ 20,000 ตัวอักษร
POST /api/v1/roundtripปกปิด ส่งเข้าโมเดลภาษา แล้วกู้คืน จบในคำขอเดียว แบบ statelessข้อความ ≤ 20,000 ตัวอักษร
POST /api/v1/redact-pdfทาดำข้อมูลส่วนบุคคลระดับตำแหน่งจริงในไฟล์ PDF รองรับทั้งไฟล์ข้อความและเอกสารสแกนPDF ≤ 50MB และ ≤ 20 หน้า
POST /api/v1/analyze-reportออกรายงานความเสี่ยง PDPA เป็นไฟล์ PDFข้อความ ≤ 20,000 ตัวอักษร
GET /api/v1/healthตรวจสถานะบริการไม่มี

นโยบายข้อมูล

ข้อความของคุณวิ่งผ่านเซิร์ฟเวอร์ของทีมที่วางอยู่บนโครงสร้าง NECTEC เท่านั้น และไม่ถูกเก็บไว้หลังคำขอจบ เส้นทางนี้เป็น stateless การจับคู่ระหว่างของจริงกับข้อมูลปกปิดถูกส่งกลับมาพร้อมคำตอบในคำขอเดียวแล้วก็หายไป log ฝั่งเราไม่มีเนื้อหาข้อความและไม่มี query string ปลายทางโมเดลภาษาคือ thaillm-8b ของ Pathumma
