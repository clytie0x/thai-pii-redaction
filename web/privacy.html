ความเป็นส่วนตัวและความปลอดภัย

AI Guard Hosted รับข้อความบนเซิร์ฟเวอร์ของทีม ตรวจจับและแทนค่าข้อมูลที่ระบบพบ ก่อนส่งเฉพาะข้อความที่ปกป้องแล้วไปยังโมเดล AI ปลายทาง

ช่องทางมีขอบเขตต่างกัน: หน้านี้อธิบาย Hosted Web App ซึ่งไม่ใช่ local-only ส่วน Desktop 3.0.0 ตรวจจับ ปกปิด vault/mapping กู้คืน และสร้างรายงานบนอุปกรณ์ และไม่มีคำสั่งเรียก provider ภายนอก เลือกไฟล์ Desktop
ข้อจำกัดสำคัญ: ระบบตรวจจับอัตโนมัติอาจพลาดหรือระบุเกินจริงได้ อย่าใส่ข้อมูลจริงที่มีความเสี่ยงสูง หากงานของคุณยอมรับความผิดพลาดนี้ไม่ได้ และควรให้มนุษย์ตรวจทานก่อนใช้งานสำคัญ

ข้อมูลเดินทางอย่างไร

1. ข้อความต้นฉบับ

เดินทางผ่าน reverse proxy และเซิร์ฟเวอร์ AI Guard เพื่อให้ระบบตรวจจับและสร้างการแทนค่า จึงไม่ใช่การประมวลผลภายในอุปกรณ์เท่านั้น

2. โมเดล AI ปลายทาง

เฉพาะข้อความที่ปกป้องและตรวจซ้ำแล้วถูกส่งไปยัง Pathumma/Tokenmind เพื่อเรียก thaillm-8b ค่าจับคู่และค่าต้นฉบับไม่ได้อยู่ใน payload นี้

3. การกู้คืน

การจับคู่มีอยู่ชั่วคราวในหน่วยความจำภายในคำขอเดียวเพื่อกู้คืนคำตอบ ไม่ถูกส่งคืนเป็น mapping และไม่ถูกบันทึกลงฐานข้อมูลผู้ใช้

4. รายงาน

PDPA Report ไม่ฝังข้อความต้นฉบับ แต่เป็นการประเมินอัตโนมัติ ไม่ใช่ใบรับรองทางกฎหมายหรือคำยืนยันการปฏิบัติตาม PDPA

การจัดเก็บและบันทึกเหตุการณ์

  • หน้าเว็บไม่ใช้ localStorage, sessionStorage, analytics หรือ tracker สำหรับเนื้อหาผู้ใช้
  • มีคุกกี้ session แบบ Secure, HttpOnly, SameSite=Strict อายุไม่เกิน 30 นาที; logout เพิกถอน session ใน process ปัจจุบันและล้างคุกกี้
  • application logs เก็บเฉพาะ operation, method, status, bytes และเวลารวมแบบโครงสร้าง ไม่เก็บ IP, query, body, prompt, คำตอบ, mapping, cookie, access code หรือ credential
  • Docker logs หมุนสูงสุด 50 MiB จำนวน 3 ไฟล์ต่อ service; โครงสร้างพื้นฐานของแพลตฟอร์มอาจเก็บ connection metadata ตามนโยบายของผู้ให้บริการแพลตฟอร์ม
  • ไฟล์รายงานอยู่ในหน่วยความจำของหน้าเว็บจนกว่าจะเปลี่ยนข้อความ รีเซ็ต ออกจากระบบ หรือปิดหน้า

ขอบเขตฟีเจอร์

Hosted edition รองรับข้อความยาวไม่เกิน 20,000 ตัวอักษร Public PDF redaction และ OCR ปิดอยู่และคืน 404 ส่วน Section 26 เป็นเพียง heuristic review signal ไม่ใช่คำตัดสินทางกฎหมาย

เหตุการณ์ด้านความปลอดภัยและคำถาม
