B / HOSTEDPRIVATE BETA

AI Guard Web App

ข้อความต้นฉบับผ่าน AIFT edge/reverse proxy และเซิร์ฟเวอร์ของทีมเพื่อการตรวจจับ ส่วน Safe AI ส่งข้อความที่ปกป้องและผ่าน policy check แล้วไปยังผู้ให้บริการ AI ผ่าน backend

ข้อความดิบ→Team service→ข้อความปกป้อง→thaillm-8b

Private Beta ใช้ shared invite gate และ Tokenmind/Pathumma thaillm-8b เพียง provider เดียว ไม่มี fallback โดย provider payload ไม่มีข้อความดิบหรือ vault/mapping · อ่านขอบเขตทั้งหมด
