AI Guard Desktop 0.1.0

ยังไม่มีไฟล์ติดตั้งของรุ่น 0.x ไฟล์รุ่น 3.0.0 เดิมถูกเก็บเข้า archive แล้ว และไม่ได้แจกจ่ายจากหน้านี้ เมื่อปล่อยรุ่นใหม่ หน้านี้จะลิงก์ไปยังไฟล์ของ release นั้นโดยตรงพร้อมค่า SHA-256

สถานะการเซ็น: เมื่อปล่อยไฟล์แล้ว installer ของ Windows จะยังไม่มี publisher signature และแพ็กเกจ macOS จะยังไม่ได้เซ็นหรือ notarize ระบบจึงอาจแสดงคำเตือนความน่าเชื่อถือ เพราะการเซ็นโค้ดยังเลื่อนไว้

Chrome Extension 0.1.0

ยังไม่มีไฟล์ ZIP ให้ดาวน์โหลด และ Chrome Web Store ยังไม่มีหน้ารายการที่เผยแพร่ ส่วนขยายต้องใช้ Desktop สำหรับ Native Messaging

ขอบเขตข้อมูลดิบ: การใช้ In-page Mask เริ่มหลังข้อความดิบเข้า DOM ของเว็บไซต์ AI แล้ว โค้ดของเว็บไซต์อาจเห็นหรือส่งข้อความนั้นได้ก่อนการปกปิด หากต้องการแยกข้อมูลดิบให้มากขึ้น ให้กรอกใน AI Guard Side Panel แล้วนำเฉพาะข้อความที่ปกปิดและตรวจทานแล้วไปวาง — Side Panel เป็นขอบเขตที่แข็งแรงกว่า อ่าน ขอบเขตความปลอดภัยของ Desktop และ Extension
AI Guard Hosted 0.1.0 มี Standard access และ Priority Invite แยกจากช่องทางดาวน์โหลด Desktop หรือ Extension ไม่เปลี่ยนขอบเขตการเข้าถึง การเก็บข้อมูล หรือข้อจำกัดของ Hosted Web
