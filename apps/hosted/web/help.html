โดยไม่ส่งข้อมูลจริง

เริ่มจากงานที่ต้องทำ อ่านสถานะบนหน้า แล้วส่งเฉพาะขั้นตอนทำซ้ำด้วยข้อมูลสังเคราะห์ อย่าส่ง access code, cookie, credential หรือข้อความจริง

เริ่มใช้งาน Hosted 0.1.0

เริ่ม Standard access ได้ทันที หรือใช้ Priority Invite ที่ออกให้

ตามงานของคุณเริ่มใช้สถานะและข้อผิดพลาดคำถามเรื่องข้อมูลแจ้งปัญหาAccessibility

Hosted 0.1.0 ให้ Standard access และ Priority Invite ใน workspace เดียว Desktop ยังคงเป็นช่องทาง local-first ที่ไม่มี provider ภายนอก หากไม่แน่ใจว่าข้อมูลออกจากเครื่องได้หรือไม่ ให้หยุดและเลือก Desktop

เริ่มจากช่องทางที่ถูกต้อง

  1. ข้อมูลต้องอยู่ในเครื่อง: Desktop (ยังไม่มีไฟล์ให้ดาวน์โหลด) ดูสถานะ
  2. เปิด Hosted 0.1.0 อ่าน boundary notice แล้วเริ่ม Standard access หรือใช้ Priority Invite ที่ออกให้
  3. เริ่มด้วยตัวอย่างสังเคราะห์ เลือก Inspect & report แล้วตรวจผล Detect ก่อน
  4. ก่อนใช้ Protect text for AI ให้ตรวจ exact protected payload และผลกู้คืนทุกครั้ง
  5. PDPA Report เป็นสรุปเพื่อทบทวน ไม่ใช่คำรับรองทางกฎหมาย

สถานะและข้อผิดพลาด

เข้าใช้ไม่ได้

Standard access ผูกกับ signed browser session ส่วน Priority ผูกกับ invite ที่ออกให้ การลองผิดซ้ำถูก rate limit หาก session หมดอายุให้เริ่ม access ใหม่

ข้อความยาวหรือรูปแบบผิด

Hosted จำกัด 20,000 ตัวอักษร สถานะ 400/413/422 หมายถึงคำขอไม่ผ่านเงื่อนไขหรือการตรวจ fail closed อย่าลดการตรวจเพื่อฝืนส่งต่อ

บริการไม่พร้อม

สถานะ 429 ให้รอก่อนลองใหม่ ส่วน 500/502/503/504 หมายถึงบริการหรือ dependency ยังไม่พร้อม เก็บข้อความต้นฉบับไว้กับคุณและลองใหม่ภายหลัง

Protect text for AI ใช้เวลานาน

คำขอ provider อาจใช้หลายนาที ระบบไม่อ้างว่ายกเลิกงานฝั่ง server ได้หลังส่งแล้ว อย่ากดซ้ำจนรู้สถานะเดิม

ขอบเขต PDF: Hosted 0.1.0 รับเฉพาะ text-layer PDF เพื่อสร้าง Protected Markdown เท่านั้น ไม่รองรับ PDF redaction หรือ OCR และ `/redact-pdf` ยังคง 404

คำถามเรื่องข้อมูล

ระบบเก็บข้อความหรือไม่?

ไม่มีฐานข้อมูลผู้ใช้และ application logs ไม่เก็บเนื้อหา แต่ Hosted ต้องรับข้อความบน edge/server เพื่อประมวลผล อ่าน lifecycle และขอบเขต provider ทั้งหมดใน หน้าความเป็นส่วนตัว

ปิดหน้าหรือ logout แล้วเกิดอะไร?

หน้าเว็บล้าง state ที่ละเอียดอ่อนและคุกกี้ session เมื่อ logout คำขอ provider ที่ส่งไปแล้วอาจยังทำงานฝั่ง server ได้ จึงไม่ควรตีความการปิดหน้าเป็นการยกเลิกปลายทาง

แจ้งปัญหาอย่างปลอดภัย

  • เวลาและ timezone โดยประมาณ
  • ช่องทาง: Desktop 0.1.0, Hosted 0.1.0 หรือ Extension 0.1.0
  • Workflow และ HTTP status หากทราบ
  • ขั้นตอนทำซ้ำและตัวอย่างสังเคราะห์ที่สร้างใหม่

Priority Invite หรือเหตุการณ์ที่เป็นความลับ: ผู้ถือ Priority Invite ใช้ช่องทางเดิมที่ได้รับ invite ปัจจุบันยังไม่มี private public inbox ที่เจ้าของอนุมัติ ห้ามโพสต์รายละเอียดลับบน GitHub

ปัญหา source code ที่ไม่มีข้อมูลลับ: เปิด GitHub Issue
